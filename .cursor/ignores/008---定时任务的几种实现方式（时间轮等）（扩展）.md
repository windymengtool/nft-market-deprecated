> # Golang 定时任务实现方式详解
>
> 在 Go 语言中，实现定时任务有多种方式，下面我将详细讲解你提到的三种方式，包括它们的区别、应用场景和具体实现示例。
>
> ## 1. for循环 + time.Sleep
>
> ### 特点
> • 最简单直接的定时任务实现方式
> • 每次循环都会阻塞当前 goroutine
> • 精度较低，受任务执行时间影响
>
> ### 应用场景
> • 简单的后台任务，对时间精度要求不高
> • 需要简单轮询的场景
> • 开发测试阶段的临时定时任务
>
> ### 示例代码
> ```go
> package main
> 
> import (
> 	"fmt"
> 	"time"
> )
> 
> func main() {
> 	go func() {
> 		for {
> 			fmt.Println("执行定时任务:", time.Now().Format("2006-01-02 15:04:05"))
> 			// 模拟任务执行时间
> 			time.Sleep(100 * time.Millisecond)
> 			// 固定间隔执行
> 			time.Sleep(5 * time.Second)
> 		}
> 	}()
> 
> 	// 防止主程序退出
> 	select {}
> }
> ```
>
> ## 2. for循环 + 时间轮(Time Wheel)算法
>
> ### 特点
> • 更高效的时间管理算法
> • 适合大量定时任务的场景
> • 实现相对复杂
> • 可以精确控制任务的执行时间
>
> ### 应用场景
> • 需要管理大量定时任务的系统
> • 对定时精度要求较高的场景
> • 需要动态添加/删除定时任务的场景
>
> ### 示例代码
> ```go
> package main
> 
> import (
> 	"fmt"
> 	"time"
> )
> 
> type Task struct {
> 	interval time.Duration
> 	job      func()
> }
> 
> type TimeWheel struct {
> 	ticker   *time.Ticker
> 	interval time.Duration
> 	slots    []map[string]*Task
> 	current  int
> 	slotNum  int
> }
> 
> func NewTimeWheel(interval time.Duration, slotNum int) *TimeWheel {
> 	tw := &TimeWheel{
> 		interval: interval,
> 		slots:    make([]map[string]*Task, slotNum),
> 		current:  0,
> 		slotNum:  slotNum,
> 	}
> 	for i := 0; i < slotNum; i++ {
> 		tw.slots[i] = make(map[string]*Task)
> 	}
> 	return tw
> }
> 
> func (tw *TimeWheel) Start() {
> 	tw.ticker = time.NewTicker(tw.interval)
> 	go func() {
> 		for range tw.ticker.C {
> 			tw.tick()
> 		}
> 	}()
> }
> 
> func (tw *TimeWheel) tick() {
> 	tasks := tw.slots[tw.current]
> 	for k, task := range tasks {
> 		go task.job()
> 		delete(tasks, k)
> 	}
> 	tw.current = (tw.current + 1) % tw.slotNum
> }
> 
> func (tw *TimeWheel) AddTask(key string, task *Task) {
> 	pos := (tw.current + int(task.interval/tw.interval)) % tw.slotNum
> 	tw.slots[pos][key] = task
> }
> 
> func main() {
> 	tw := NewTimeWheel(1*time.Second, 60) // 1秒间隔，60个槽
> 	tw.Start()
> 
> 	// 添加定时任务
> 	tw.AddTask("task1", &Task{
> 		interval: 5 * time.Second,
> 		job: func() {
> 			fmt.Println("执行任务1:", time.Now().Format("15:04:05"))
> 		},
> 	})
> 
> 	tw.AddTask("task2", &Task{
> 		interval: 10 * time.Second,
> 		job: func() {
> 			fmt.Println("执行任务2:", time.Now().Format("15:04:05"))
> 		},
> 	})
> 
> 	// 防止主程序退出
> 	select {}
> }
> ```
>
> ## 3. for循环 + time.Ticker
>
> ### 特点
> • 比 time.Sleep 更精确
> • 不会受任务执行时间影响
> • 适合固定间隔的定时任务
> • 资源消耗比 time.Sleep 略高
>
> ### 应用场景
> • 需要固定频率执行的定时任务
> • 对时间精度有一定要求的场景
> • 需要同时处理多个定时任务的场景
>
> ### 示例代码
> ```go
> package main
> 
> import (
> 	"fmt"
> 	"time"
> )
> 
> func main() {
>  创建一个5秒的定时器
> 	ticker := time.NewTicker(5 * time.Second)
> 	defer ticker.Stop()
> 
> 	done := make(chan bool)
> 	
> 	go func() {
> 		for {
> 			select {
> 			case <-done:
> 				return
> 			case t := <-ticker.C:
> 				fmt.Println("定时任务执行:", t.Format("2006-01-02 15:04:05"))
> 				// 模拟任务执行时间
> 				time.Sleep(2 * time.Second)
> 			}
> 		}
> 	}()
> 
> 	// 运行30秒后停止
> 	time.Sleep(30 * time.Second)
> 	done <- true
> 	fmt.Println("定时任务停止")
> }
> ```
>
> ## 三种方式对比
>
> | 特性              | time.Sleep | 时间轮 | time.Ticker |
> | ----------------- | ---------- | ------ | ----------- |
> | 实现复杂度        | 简单       | 复杂   | 中等        |
> | 时间精度          | 低         | 高     | 高          |
> | 资源消耗          | 低         | 中等   | 中等        |
> | 适合任务数量      | 少量       | 大量   | 少量到中等  |
> | 动态添加/删除任务 | 不支持     | 支持   | 有限支持    |
> | 任务执行时间影响  | 有影响     | 无影响 | 无影响      |
>
> ## 推荐选择
>
> 1. **简单场景**：使用 `time.Ticker`，它提供了良好的平衡
> 2. **大量定时任务**：使用时间轮算法
> 3. **临时/简单任务**：可以使用 `time.Sleep`，但不推荐生产环境使用
>
> 在实际开发中，对于复杂的定时任务需求，也可以考虑使用现成的库如 `github.com/robfig/cron` 等。
