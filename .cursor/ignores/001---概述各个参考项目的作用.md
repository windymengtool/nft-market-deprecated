# 001---各个作用

根据搜索结果，我可以对各个参考项目的作用进行概括：

> 1. `nft-market-fe`: 基于Next.js的NFT市场前端项目，负责用户界面展示和交互。
>
> 2. `EasySwapContract`: NFT交易的智能合约项目，实现了基于订单簿模型的NFT交易系统，包括限价买卖、市价买卖等核心功能。
>
> 3. `EasySwapBackend`: NFT市场的后端API服务，提供用户登录、NFT集合管理、NFT物品管理、交易订单等接口服务。
>
> 4. `EasySwapSync`: 区块链事件同步服务，负责将链上的NFT交易事件同步到数据库中，保持链上数据与后端数据的一致性。
>
> 5. `EasySwapBase`: 基础工具库项目，为其他服务提供通用的工具函数、数据库操作、HTTP客户端、日志等基础功能支持。
>
> 这五个项目共同构成了一个完整的NFT交易市场系统，实现了从智能合约、后端服务到前端界面的全栈功能。





# 002---技术栈

根据代码分析，我整理了各个项目使用的主要技术栈：

| 项目名称         | 主要技术栈                                                   |
| ---------------- | ------------------------------------------------------------ |
| nft-market-fe    | - Next.js (React框架)<br>- Node.js v20.11<br>- Docker容器化<br>- PM2进程管理<br>- pnpm包管理器 |
| EasySwapContract | - Solidity v0.8.20<br>- Hardhat开发框架<br>- OpenZeppelin合约库<br>- Ethers.js<br>- Web3.js<br>- TypeChain类型生成 |
| EasySwapBackend  | - Go v1.21<br>- Gin Web框架<br>- GORM数据库ORM<br>- Redis缓存<br>- MySQL数据库<br>- go-ethereum客户端库<br>- Swagger API文档 |
| EasySwapSync     | - Go v1.21<br>- Cobra命令行工具<br>- GORM数据库ORM<br>- Redis缓存<br>- MySQL数据库<br>- Docker容器化 |
| EasySwapBase     | - Go v1.21<br>- go-ethereum客户端库<br>- 通用工具库(HTTP、日志、验证等)<br>- ERC721/ERC1155合约接口 |

- 以太坊Sepolia测试网
- MySQL数据库
- Redis缓存
- Docker容器化
- Git版本控制
